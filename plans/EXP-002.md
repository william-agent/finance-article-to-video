# EXP-002：Hybrid Production Pipeline 最小可行實驗

- **狀態**：規劃中（preflight 完成 2026-08-16）。**未執行。**
- **前提**：EXP-001 為 baseline（deterministic finishing 已驗證）。本實驗不重做已驗證的事。
- **鐵律**：涉及付費、credential、商用授權 → 先停下取得使用者確認。每個 Agent／模型／工具／成本／授權／責任都要記錄。

## 問題定義

EXP-001 證明「HyperFrames＋好內容＝快速 PoC」。它**沒有**回答的，就是本實驗的對象：

1. **VGM 品質**：Animate Anyone 類生成鏡頭能否穩定達到財經內容可用的品質？
2. **語音表演**：有沒有一個聲音方案在自然度／情緒／停頓上顯著優於 edge-tts，且商用授權乾淨？
3. **Agent 剪輯判斷**：剪輯決策能否成為明確、可歸責、有記錄的角色（而不是散落在對話裡）？
4. **可修改性**：成品的單點修改（換一句話、改一個鏡頭）成本多高？
5. **成本**：一支 hybrid 片段的真實單價？
6. （批次穩定性留給 EXP-003；單支成功不宣稱 production-ready——EXP-001 的教訓）

## 核心假設（H）

> 一條「intent → VGM 鏡頭 → 語音表演 → Agent 剪輯（有記錄）→ deterministic finishing」的混合管線，
> 能在**一個 15–25 秒片段**上，做出使用者「不會想滑走」的品質，且每個決策可歸責、每分錢可解釋。

刻意縮小邊界：**一個片段，不是一支完整影片**。選 EXP-001 最弱的一段（beat1 靜態停留段）重做，直接對照。

## 五個工作流（可獨立 PASS/FAIL）

### W1 剪輯決策角色化（免費，可立即做）
- 定義 **Editor Agent** 角色：輸入 storyboard＋素材清單，輸出 **EDL（Edit Decision List）JSON**——每個鏡頭的取捨、時點、理由、決策者標識。
- EXP-001 的教訓入檔：當時所有剪輯決策由 conductor 隱式完成、無記錄。
- **PASS**：片段的每一個剪輯決策都在 EDL 內、機器可讀、有理由、有歸責。

### W2 VGM 生成鏡頭（付費，等使用者核可）
本機無 GPU（EXP-001 audit），本地開源路線（Wan 2.2／HunyuanVideo／Animate Anyone，需 24GB VRAM）不可行；雲 GPU 租用設置成本高。**建議 API-first**。2026-08 行情（來源見文末）：

| 供應商 | 價格 | 備註 |
|---|---|---|
| Wan 2.6 API | ~$0.05/sec | 最便宜，原生 1080p |
| Kling 3.0 | ~$0.09–0.14/sec | 性價比口碑最好 |
| Sora 2 | ~$0.10/sec | |
| Runway Gen-4.5 | ~$0.20/sec | 專業工作流成熟 |
| Veo 3.1 Lite / Standard | $0.05 / $0.40–0.75/sec | Standard 含音訊、lip-sync 最佳 |
| HeyGen avatar API | 另查 | 「AI 財經主播」路線；與 HyperFrames 同公司，整合可能最順 |

- 測試量級：每家 1–2 支 10 秒鏡頭，總成本估 **US$3–8**。
- **PASS**：至少一家的鏡頭在手機上看不出致命瑕疵（手部／文字／閃爍），且條款允許商用。
- **授權**：各家商用條款以生成當下有效版本為準，逐家存證。

### W3 語音表演（部分免費額度，帳號需使用者開）
2026-08 調研：**MiniMax Speech 2.8 HD**（台灣腔自然度目前口碑第一）、**ElevenLabs v3**（萬人盲測 86.2% 好感度）、**Azure Speech**（商用條款最正式）、F5-TTS（開源 clone 強，但無 GPU 本機不可行）。
- 協議：同一段旁白（beat1 全文）各家合成 → 盲測給使用者手機聽 → 選出者需通過「明顯優於 edge-tts baseline」。
- **PASS**：有明確勝出者且商用授權路徑乾淨。

### W4 Deterministic Finishing 收編 VGM（免費，可立即做）
- 驗證 HyperFrames 組合裡放 `<video>` 背景（VGM 產物）＋圖表／字幕 overlay，仍然：lint 過、確定性成立（SHA256 重現）、渲染時間可接受。
- **在拿到真 VGM 之前用替身片**：FFmpeg 本地合成的動態測試片（zoompan/噪聲動畫）當 stand-in，先把合成層打通。
- **PASS**：替身片合成 → 兩次渲染 SHA256 一致；VGM 到位後替換重測。

### W5 成本／授權／責任帳本（貫穿）
- `ledger.json`：每次生成呼叫的供應商、模型版本、參數、費用、授權條款快照連結、負責 Agent。
- **PASS**：片段成品的每一秒畫面和每一句聲音都能回答「誰做的、用什麼、花多少、憑什麼商用」。

## 責任分工

| 角色 | 承擔者 | 記錄位置 |
|---|---|---|
| 意圖確認／預算核可 | 使用者 | 本檔案＋Discord |
| Storyboard／facts | conductor（沿用 EXP-001 機制） | facts.json + storyboard.json |
| **Editor Agent（新）** | conductor 或獨立 subagent（W1 決定） | EDL JSON |
| VGM 生成 | 外部 API（W2 選定） | ledger.json |
| 語音 | 外部 TTS（W3 選定） | ledger.json |
| Finishing | HyperFrames（確定性已證） | render log |
| QA | 沿用 EXP-001 機制＋使用者 G3 | qa-checklist |

## 主要 Blockers（執行前需解）

1. **付費核可**：W2＋W3 估總預算 **US$10 內**——需使用者同意額度與可開帳號的供應商。
2. **Credential**：各 API 金鑰由使用者提供（不繞權限）。
3. edge-tts 商用 BLOCKED（僅存為 baseline 對照）。
4. Codex fleet 權限審批模型（pending-permission #5）——EXP-002 若用 subagent 當 Editor，先解或改用 Claude 系 subagent。

## 排序（無需付費的先行）

1. W4 替身片合成驗證（立即）
2. W1 EDL schema＋Editor Agent 定義（立即）
3. → 停：使用者核可預算＋開帳號 →
4. W3 盲測 → W2 VGM 測試鏡頭 → 端到端片段 → G3 手機驗收
