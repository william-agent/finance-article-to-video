## 設計決定

1. **`facts.json` 是安全鎖**：[2] 的 LLM 只准引用帳本內數字；[5] 再反向比對成品。數字幻覺兩頭堵死——財經產線與一般內容產線的最大差異。
2. **字幕不經 STT**：旁白稿是自產的，字幕直接從稿子生成，零錯字。
3. **MVP 刻意排除**：ComfyUI 縮圖、高階 TTS、橫式版本——第一跑只為暴露斷點。
4. **分工**：[3] 三路素材可交 fleet 並行；[2] 編譯是品質決定站，由 conductor 把關。

## 模型依賴 Audit（2026-08-15，使用者質疑後補）

> 質疑：「不需要外部 API 嗎？VLM 或 VGM？」——答案：比想像少，但不是零。

```
工序            需要的能力   由誰承擔          外部API?
─────────────────────────────────────────────
[1] 數據抽取    LLM         conductor(Claude) △¹
[2] 分鏡編譯    LLM         conductor         △¹
[3] 圖表        無模型      程式繪圖          否
[3] 旁白TTS     語音合成    edge-tts          是²★
[3] 配圖/縮圖   圖像生成    ComfyUI…          ✗³斷點!
[4] 組裝渲染    無模型      Chrome+FFmpeg本地 否
[5] QA看畫面    VLM         conductor(多模態讀frame) △¹
[5] QA聽旁白    STT         本地whisper       否
    VGM         不存在      —                 否⁴
```

1. **△ conductor 本身就是 LLM+VLM**（已在付的成本）。正確說法是「不需要新增的 LLM/VLM 訂閱」，不是「不需要外部 API」。QA 看畫面 = 逐拍抽 frame，conductor 直接讀圖比對 facts.json。
2. **TTS 是 MVP 唯一新增外部呼叫**：edge-tts（微軟免費端點、無金鑰、zh-TW-HsiaoChenNeural）。升級路線才是 ElevenLabs。QA 閉環：TTS 音檔 → 本地 whisper 轉回文字 → diff 腳本，錯字漏句全自動抓。
3. **✗ 本機無 GPU**（nvidia-smi 不存在）→ ComfyUI 縮圖線在這台機器不可行。未來三選一：圖像 API／雲 GPU／使用者自有 GPU 機器掛遠端節點。**「最後一定會用 ComfyUI」撞上的第一面牆是硬體。**
4. **VGM 整條線不存在**——影片是渲染的不是生成的，這正是確定性與數字可驗證的來源。生成式片段若未來要加，必然是外部 API。

環境就緒度：Node 24 ✓、puppeteer Chrome 已快取 ✓、FFmpeg ✓、edge-tts 可裝 ✓。
