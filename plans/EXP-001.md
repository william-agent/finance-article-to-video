## 設計決定

1. **`facts.json` 是安全鎖**：[2] 的 LLM 只准引用帳本內數字；[5] 再反向比對成品。數字幻覺兩頭堵死——財經產線與一般內容產線的最大差異。
2. **字幕不經 STT**：旁白稿是自產的，字幕直接從稿子生成，零錯字。
3. **MVP 刻意排除**：ComfyUI 縮圖、高階 TTS、橫式版本——第一跑只為暴露斷點。
4. **分工**：[3] 三路素材可交 fleet 並行；[2] 編譯是品質決定站，由 conductor 把關。

## Audit v2 修正（使用者第二次質疑，全數採納）

第一次 audit 的每一項結論都被指出越界，逐條修正：

1. **無 GPU ≠ 硬體 audit 完成**。`nvidia-smi` 不存在只代表無可用 NVIDIA 驅動/裝置。無 GPU 不妨礙簡單 HTML + CPU FFmpeg，但**不能據此假定逐幀 Chrome render 足夠快**——55 秒 @30fps ≈ 1,650 幀，必須實測。
2. **「FFmpeg ✓」是未經驗證的宣稱**。未查 `ffmpeg -version`、encoder 清單、AAC/H.264 支援、headless Chrome 實際啟動、CJK 字型、CPU/RAM/磁碟、cgroup 限制、Puppeteer 相容性。`ls ~/.cache/puppeteer` ≠ 存在可執行且相容的 Chrome。
3. **edge-tts 降級為「可替換的 PoC 依賴」**。`pip index versions` 只證明 PyPI metadata 可查；未證明可安裝、端點可連、聲線可用、無限流。更重要：edge-tts 是第三方對 Edge 消費者朗讀端點的封裝，**非 Microsoft 正式免費商用 API、無 SLA、商用權利不明**。Production 必須改接正式商用 TTS（如 Azure Speech）或取得書面授權。
4. **「conductor 就是 LLM/VLM」仍是外部雲端依賴**。未定義可重跑的呼叫介面、費用、額度、版本、延遲、timeout、retry、隱私與失敗 fallback 之前，這是互動式人工流程，不是已接入的自動產線。
5. **抽幀 ≠ 影片 QA**。抽幀抓不到閃爍、黑格、轉場破圖、凍結、掉幀、字幕跳動、A/V sync。必須檢查最終編碼後的 MP4：全幀異常掃描 + scene-boundary 檢查 + 真人完整觀看。
6. **Whisper 對稿不是正確性 oracle**。抓不到錯誤重音、多音字、金融專名、英文 ticker、數字斷句、爆音、機械感，且自身會辨識錯誤。僅可做 coverage 輔助；關鍵名詞與數字需發音詞典、音訊量測、人工試聽。
7. **「與 facts.json 一致」≠ facts.json 為真**。必須保留來源、擷取時間、時區、幣別、單位；衍生數值由程式重算；畫面/旁白/字幕中所有關鍵數字 100% 與來源一致。
8. **「沒有 VGM」= 產品被限定為模板式 motion graphics**，不等於自動取得商用品質。品牌級 art direction、B-roll、獨特配圖、人物畫面目前架構不滿足。
